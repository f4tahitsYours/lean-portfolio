# Projects Images Folder

Tempatkan gambar/screenshot project Anda di folder ini.

## Format File
- **Format yang didukung**: JPG, PNG, WebP
- **Ukuran yang disarankan**: 1200x800px (rasio 3:2)
- **Ukuran file maksimal**: < 500KB (untuk performa optimal)

## Penamaan File
Gunakan nama file yang sesuai dengan yang ada di `src/projectsData.ts`:

### Contoh:
- `industrial_defect_detection.jpg` - Project Industrial Defect Detection
- `sentiment_analysis.jpg` - Project Sentiment Analysis
- `object_detection.jpg` - Project Object Detection

## Tips
1. Gunakan screenshot yang menarik dan representatif dari project Anda
2. Pastikan gambar memiliki kualitas yang baik
3. Compress gambar untuk performa web yang lebih baik
4. Gunakan nama file tanpa spasi (gunakan underscore `_` atau dash `-`)

## Placeholder
Jika belum ada gambar, sistem akan menampilkan placeholder dengan gradient dan judul project.
